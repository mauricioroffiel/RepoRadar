What it solves

Stack

Frontend

Backend
TypeScript on Node.js (22.18 or newer) with a CLI called gd, managed with pnpm
Database
—
AI

alibaba / open-code-review
Go★ 54,169+4,383 this week

What it solves

Reviewing code changes by hand is slow, and general AI agents often skip files or point to the wrong lines. This CLI reviews Git diffs for developers and CI pipelines with line-level comments.

Stack

Frontend
Terminal UI built with Bubble Tea, Lip Gloss and Glamour
Backend
Go with Cobra CLI
Database
—
AI
OpenAI and Anthropic compatible LLMs (also AWS config), a tool-using agent, MCP Go SDK, tiktoken token counting
Deploy
CLI tool (npm package.json also present)

What's new here

It mixes fixed code logic with an LLM agent: code, not the model, picks files, bundles related ones and matches rules, and each bundle runs in a sub-agent. This is meant to avoid missed files and line drift, and uses about 1/9 of the tokens in its benchmark against Claude Code.
