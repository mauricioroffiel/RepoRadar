ag-ui

by ag-ui-protocolTypeScript21,553 stars+2,966 this week

ranst91Top contributor at ag-ui-protocol

What it solves

AI agents stream tokens, call tools, share state and pause for humans, and every framework wires this to the user interface differently. AG-UI gives developers one standard way to connect any agent to any app.

What’s new here

It defines one open, event-based protocol: the agent streams typed events (text, tool calls, state updates, human pauses) over HTTP, and any client can render them. The 1.0 spec is frozen with a JSON Schema, and the TypeScript, Python and .NET SDKs are generated from it.
